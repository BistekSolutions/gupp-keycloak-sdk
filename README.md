# General

This project exposes various constant/enum classes and interfaces for the implementation of the gupp-keycloak-user-provider-spi <br/>
and for use in implementing projects (e.g. [ProviderPathConstants](src/main/java/com/bismarck/keycloak/gupp/request/ProviderPathConstants.java))

## Implementation

If you want to use this project as a maven-library, you have to either fetch it locally or use your own nexus.
